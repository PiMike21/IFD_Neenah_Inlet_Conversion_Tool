# IFD_Neenah_Inlet_Conversion_Tool
Offline web app that turns the Neenah grate capacity catalog into InfoDrainage-ready inlet curves. Search 155 digitized configurations, view capture and bypass flow, and download the two-column rated-by-flow CSV — or recalculate for your own gutter slopes, roughness, and depth. Runs entirely in your browser. On-grade gutter flow only.
